#  Command-Line Habit Tracker

This is a simple python project for keeping track of daily habits.
Users can add habits, mark them as completed, and check their current streak.

##  Project Objective

The Habit Tracker allows users to:

- Create and manage daily habits
- Add descriptions to habits
- Mark habits as completed for the current day
- Track completion streaks
- Store habit history locally
- Save their data for later

## Features

### 1. Add Habit
Users can create a new habit by:
- Habit name
- Habit description

### 2. Daily Check-In
Users can select a habit and mark it as completed for the day.
A habit cannot be checked twice on the same day.

### 3. View Progress
Users can see:
- Habit name
- Description
- Current streak
- Total completed days

### 4. Delete Habit
Users can remove habits that are no longer needed.

### 5. Save Data
The habit details and completion dates are saved in JSON file.
so, the data will still be there when the program is opened again.

##  Technologies Used

- Python
- JSON
- Command Line Interface (CLI)
- File Handling
- Date and Time
